# kilnbook.co

The marketing site for Kilnbook: booking and class-management software for pottery studios.
Built with [Astro](https://astro.build) 5 as a fully static site and deployed on Netlify.

The product app lives elsewhere; this repo is only the public site at https://kilnbook.co.

## Requirements

- Node 22 or newer (`.nvmrc` pins 22)
- pnpm 9 (`corepack enable` will pick up the version in `package.json`)

## Environment

The build needs one variable:

| Variable                 | What it is                                                                                     | Example                     |
| ------------------------ | ---------------------------------------------------------------------------------------------- | --------------------------- |
| `PUBLIC_BOOKING_API_URL` | Base URL of the booking service. Used for the "Book a demo" form action (`/demo-requests`). | `https://book.kilnbook.co` |

It is declared in the `env.schema` block of `astro.config.mjs`, read at build time and baked into
the HTML. If it is missing or not a URL, `pnpm build` fails with
`PUBLIC_BOOKING_API_URL is missing` (and `pnpm dev` shows the same error in the browser). Locally, copy `.env.example` to `.env`:

```sh
cp .env.example .env
```

On Netlify it is set under **Site configuration → Environment variables** for all deploy contexts.
Deploy previews use the same value as production.

## Running locally

```sh
pnpm install
pnpm dev        # http://localhost:4321
```

Other scripts:

```sh
pnpm build      # static build into dist/
pnpm preview    # serve dist/ locally
```

## Project layout

```
src/
  pages/            one file per route; features/ and blog/ are nested routes
  content/blog/     journal posts in Markdown (frontmatter schema in src/content.config.ts)
  layouts/Base.astro  <head>, header and footer for every page
  components/       Header, Footer, DemoForm
  styles/global.css   all styles; colour variables at the top
public/
  images/           hand-drawn SVG illustrations
  robots.txt
```

`/sitemap.xml` is generated by `src/pages/sitemap.xml.ts`. If you add a page under `src/pages`,
add its path to the list there. Journal posts are picked up automatically.

### Adding a journal post

Create `src/content/blog/<slug>.md` with this frontmatter:

```md
---
title: "Post title"
description: "One or two sentences, used for the listing and the meta description."
pubDate: 2026-10-01
author: "Your Name"
---
```

The URL is `/blog/<slug>`.

## Deploying

Netlify builds every push. `main` is production (https://kilnbook.co); every pull request gets a
deploy preview. Build settings live in `netlify.toml`:

- build command: `pnpm build`
- publish directory: `dist`

Keep `pnpm-lock.yaml` committed; Netlify installs with `--frozen-lockfile`.

## Who to ask

The site is designed and maintained with Brickfold Studio. Copy changes can go straight to a PR
against `main`; for anything that changes layout or the design, loop in Brickfold.
